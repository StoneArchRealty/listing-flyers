# Listing flyers

Public hosting for Stone Arch Realty listing flyers (brokered by LPT Realty), used as image links in NorthstarMLS Matrix email signatures for reverse prospecting.

Images only. Nothing private goes in this repo; it is public.

Flyers are built in the private `Stone-Arch-Realty-AI` repo (`workflows/reverse-prospecting/`) and copied here as `flyers/<address>-flyer.png`.

Kyle's email signature images live in `signature/` (built in `Stone-Arch-Realty-AI/marketing/email-signature/`). Outlook loads them by URL, so don't rename or delete them.
